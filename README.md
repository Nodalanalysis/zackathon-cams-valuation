# CAMS Valuation & Financial Due Diligence

## Project Overview
This repository contains the institutional equity research model and valuation implementation for Computer Age Management Services (CAMS), submitted for Zackathon. The solution relies on a comprehensive, multi-scenario financial model.

## Implementation Details
The core implementation is provided in the uploaded Excel workbook, which is structured into the following modules:
1. **IC Summary & Multi-Candidate:** High-level investment thesis and candidate comparison.
2. **CAMS Integrated DCF:** Discounted cash flow valuation modeling.
3. **Financial DD & Cash Reconcil:** Financial due diligence and cash flow reconciliation.
4. **Scenario & Regulatory Shock:** Sensitivity analysis testing market structure variables and regulatory impacts.

## Usage
Download the `.xlsx` file and open it in Microsoft Excel or compatible spreadsheet software. No additional scripts or software dependencies are required to run this model.
